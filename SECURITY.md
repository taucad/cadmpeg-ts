# Security

Do not open public issues for vulnerabilities. Use GitHub's private
vulnerability reporting for `taucad/cadmpeg-ts`.

Supported releases are the latest stable version and the latest beta. A
vulnerability in the cadmpeg engine itself is also reported upstream; this
package ships a fix as soon as the pinned tag or a patch carries it. Reports should include the
affected version, host, reproduction, and expected impact. Maintainers will
acknowledge a report, coordinate a fix, and publish through the normal signed
CI release pipeline.
